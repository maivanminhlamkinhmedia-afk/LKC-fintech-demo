## Cause and local correction

The manifest key `DRAFT` is an identity/cleanup journal key, not a frozen snapshot of title, body, cover, sources or token. `createFixtures` initially seeds an empty DRAFT, while `discoverCreatedArticles` preserves only identity and ownership fields. Source inspection of EDIT-13/14, MED-15 and MED-23-COVER, combined with their final PASS records and the PREV assertion locations, **confirms the shared-fixture premise defect** for PREV-03, PREV-07/08/12 and PREV-23. The MED-23 retained cover and `attachFixtureCoverMatrix` null-cover guard confirm the incompatible PREV-13/14/15 setup; the safe log does not expose its exact throw.

`cms-preview.spec.ts` now compares scope headings with the exact persisted Article snapshot and verifies the same Article stays unchanged. Anonymous/non-CMS/revocation negative assertions also use the actual persisted title, avoiding a false pass from an obsolete seed string. Cases needing empty fields or a null-cover attach create their **own DRAFT through the real new-article UI**, immediately journal its exact ID with `discoverCreatedArticles`, and verify owner/status/slug/title/schema/cover before use. PREV-07/08/12 additionally checks empty document, excerpt, category, source count and absent profile before preview, then checks no write. PREV-13/14/15 attaches and clears its cover on its own journaled article; foreign-uploader byte access and unrelated-byte denial remain unchanged. PREV-23 saves long Vietnamese body text on its own article before testing 390/768/1280 widths, verifies rendered content and persisted no-write snapshot. No product code or baseline case changed, and no fixture/cleanup authority expanded.

For PREV-17/18, only safe nested phase steps were added: own-list, SUBMITTED-list, new route, persisted editor link and popup. The exact allowlist in `diagnostics.mjs` accepts those five codes; a test verifies permitted records and rejection of an unknown code. All operations and assertions remain. This is **diagnostic only**, not a claim that the timeout is fixed. A fresh guarded run after review/CI is needed to locate that await if it recurs. No timeout, retry or skip changed.
